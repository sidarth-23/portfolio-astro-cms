# @sidshub/cms-lib-editor

Shared Payload rich-text editor helpers for CMS and web rendering.

## HTML Rendering API

Use the canonical renderer entry:

```ts
import {
  renderRichTextToHTML,
  createThemeRichTextRenderer,
  getThemeComponents,
} from "@sidshub/cms-lib-editor/web/html";
```

- `renderRichTextToHTML` uses the default `daisyui` theme.
- `createThemeRichTextRenderer("tailwind")` creates a renderer for an explicit theme.
- `getThemeComponents(theme)` returns block components for custom renderer composition.

### Breaking change

Theme-specific import paths were removed:

- Removed: `@sidshub/cms-lib-editor/web/html/daisyui`
- Removed: `@sidshub/cms-lib-editor/web/html/tailwind`

Use `@sidshub/cms-lib-editor/web/html` and select theme through `createThemeRichTextRenderer` when needed.

## Shared web runtime

Import client initializers from `@sidshub/cms-lib-editor/web/html/client`:

```ts
import {
  initCodeBlocks,
  initImageGallery,
  initTableOfContents,
} from "@sidshub/cms-lib-editor/web/html/client";
```

### initCodeBlocks(root?)

- Enhances code blocks generated by lexical renderers.
- Adds tab switching, overflow dropdown handling, tab icon syncing, and copy-to-clipboard behavior.
- `root` defaults to `document`.
- Returns a cleanup function.

### initTableOfContents(options?)

- Syncs active TOC link state with scroll/hash for heading anchors.
- Defaults:
  - heading selector: `"[data-toc-content] :is(h2[id], h3[id])"`
  - link selector: `"[data-toc-link]"`
  - active classes: `["opacity-100", "font-medium"]`
- Supports optional `onLinkClick` callback for app-shell behavior.
- Returns a cleanup function.

## Shared web styles

Import shared structural rich-text styles:

```css
@import "@sidshub/cms-lib-editor/web/html/styles.css";
```

This stylesheet includes reusable lexical output styles for code blocks, captions, panels, and gallery structure.
