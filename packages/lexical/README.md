# @sidshub/lexical

Shared Payload Lexical helpers for CMS and web rendering.

## Shared web runtime

Import client initializers from `@sidshub/lexical/web/client`:

```ts
import { initCodeBlocks, initTableOfContents } from "@sidshub/lexical/web/client";
```

### `initCodeBlocks(root?)`

- Enhances code blocks generated by lexical renderers.
- Adds tab switching, overflow dropdown handling, tab icon syncing, and copy-to-clipboard behavior.
- `root` defaults to `document`.
- Returns a cleanup function.

### `initTableOfContents(options?)`

- Syncs active TOC link state with scroll/hash for heading anchors.
- Defaults:
  - heading selector: `"[data-toc-content] :is(h2[id], h3[id])"`
  - link selector: `"[data-toc-link]"`
  - active classes: `["border-primary", "text-base-content", "opacity-100", "font-medium"]`
- Supports optional `onLinkClick` callback for app-shell behavior (for example: close a mobile drawer).
- Returns a cleanup function.

## Shared web styles

Import shared structural rich-text styles:

```css
@import "@sidshub/lexical/web/styles.css";
```

This stylesheet includes reusable lexical output styles for:

- Code figure counters and captions
- Code panel/header/action spacing behavior
- Image figure/caption formatting
- Prose code-block spacing normalization

## Required markup contract

For TOC behavior, ensure your rendered HTML includes:

- A content container with headings that match the heading selector (default: `[data-toc-content]` with `h2[id]` / `h3[id]`).
- TOC links with `data-toc-link` and a matching `data-toc-id="<heading-id>"`.
