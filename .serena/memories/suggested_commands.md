Install: `bun install`. Dev server: `bun run dev` (localhost:4321). Build/type-check: `bun run build` (astro check + astro build). Preview production: `bun run preview`. Type-check only: `bunx astro check`. Formatting: `bunx prettier --write --plugin prettier-plugin-astro "src/**/*.{astro,ts,tsx,js,mjs,css,md,mdx}"`. Git basics on Linux: `git status`, `git diff`, `git add`, `git commit`.
